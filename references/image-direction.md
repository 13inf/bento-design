# 海报图像方向

用户需要位图海报或视觉稿时使用。要求可编辑文件时选择相应载体，不用一张位图冒充可编辑设计。

## 先确定几个决策

主张、标题换行、第一视觉、逐卡角色、字级差、空白、用色与图像特征。把这些写入工具参数或提示词，而不是只写风格形容词。

参考资料分角色：原稿提供事实，风格图提供视觉语言，反例帮助定位需要改变的决策。旧稿被否定时，可以只转写必要文案，避免旧构图继续影响结果。

选择少量与本次方向最相关的参考，不复制图中的品牌资产、产品性能数字、测量线、界面遮罩或下载提示。

版式数值从 [参考图参数台账](reference-measurements.md) 选择，并注明最终采用值。图中产品性能参数不能带入新内容；设计参数则应写进提示词。区分默认字距、正文行距、纵向段距、卡缝与半径，不仅写“紧凑、大圆角”。

## 提示词骨架

```text
产物：尺寸、媒介与用途，一张平面海报。
主张：一句话及项目名的层级。
形式：宣言排版 / 产品特写 / 信息 Bento / 画廊。
构图：主卡、辅助卡角色，公共边线与安全区。
文字：最终原文与必要换行，区分主张、说明、注释和署名。
字级：最终字体、样式、标题/正文/注释字号；可从 3:1 关系起步。
字距与行距：默认字距或本次明确的调整值；标题与正文行距分别写。
空间：引子→标题、标题行间、标题→正文的距离；横/纵卡缝；注明单位或相对尺度。
圆角：使用短边 18% 近似时写明短边与半径；改固定半径则写本次适配值。
色彩：背景与卡片 HEX；哪个完整短语使用哪些渐变节点，朝什么方向。
图像：主体、姿态/局部、材质、背景，具体表达什么。
边界：不能补造的参数、结果和状态；示意标注。
本次避免：与实际误差相关的少数对象或结构。
```

不要在字级和内容未确定时固定整页各区百分比。不要用不断加长的禁止词列表代替正向构图。正文需可读，不能因为“极简”而被挤成微字。

## 常见偏差与对应改变

| 可观察偏差 | 改变的决策 |
|---|---|
| 大环境场景抢走注意 | 改成文字主卡或聚焦特征的产品局部；确需场景时减少竞争元素 |
| 每卡都重复标题、胶囊、说明、插画 | 为每卡选主导方式，保留容器一致，改变内部表达 |
| 无关的立体小物件越来越多 | 去掉不解释当前主题的对象，保留图像特征与空白 |
| 项目名、功能名、说明都很粗 | 重新分配主张、解释、注释的字级和字重 |
| 生成器自行添加宣传文字或百分比 | 用准确原文替换或删除，不把新增语句当用户事实 |

以上不是对场景摄影、三列布局、3D 或等大卡的普遍禁令。用户明确需要时尊重选择，问题由本次组合和具体任务判断。

## 一个通用方向示例

> 为一个产品概念制作竖版 Bento 海报。用“把重点，/放在眼前。”作为两行文字主卡，项目名作较小引子。主张与短说明约 3:1，标题到说明留出约 .75 个标题字号的可见空白。浅灰白基底，少量深色卡；只让一个完整短语使用平滑同色系渐变。用大文字、产品局部与少量辅助文字组成非对称网格，卡片共用边线与圆角，内部不复制同一模板。产品仅在有素材或已说明概念示意时呈现；缺失素材明确占位。逐字保留用户提供的文案、单位和署名，不新增结果或参数。

实际调用前替换为用户的主张与准确文案。没有用户素材时，不把这段示例当成真实产品介绍。

## 生成后检查

先缩至约 10% 看主次，再按目标尺寸核对原文与可读性。逐卡说清主导方式，检查中文断行、图像特征、渐变浅端、裁切、署名、数字与示意标注。

发现错误后进行针对性修订，列清保留项。不要在每轮纠错时顺带重做无关部分。图像模型不能保证精确字号、字距或圆角；需要精确数值时使用可控排版工具设置并检查。文件完整、生成成功或结构校验通过，都不能替代实际视觉检查或用户认可。
