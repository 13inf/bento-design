# 字重、比例与色彩

以下是可调整的起步参数。使用实际字体、输出尺寸与观看距离校正，不宣称任何品牌的官方规格。原图的完整色号、字体名、字号、默认字距与段距见 [参考图参数台账](reference-measurements.md)；原始标注与本页实施建议分开保存。

## 字体角色

| 角色 | 起步建议 | 用途 |
|---|---|---|
| 项目小引子 | 正文级或稍大，400–500 | 交代身份，未必抢第一眼 |
| 展示主张 | 正文约 3 倍，600–700 | 承担整页主要视觉 |
| 功能/分段标题 | 正文约 1.3–1.8 倍，500–600 | 标记内容层级 |
| 解释正文 | 400–500，可读的中性灰 | 说明与当前主张直接相关的信息 |
| 参数名与注释 | 正文级或稍小 | 带单位、来源、范围和必要限制 |

不要让项目名、主张、功能名、标签一起又粗又大。轻薄主题可用更轻字重，性能主题可更实，但整组应保持一致。

有 Inter、Source Han Sans 等字体时，可以使用实际存在的字重；没有就使用用户字体或系统无衬线回退。字体文件不随本项目提供，不能据此假定另有再分发授权。

中文先用正常字距，再检查连排笔画、标点与英文混排。原图英文只标“默认字距”，没有可照搬的负字距值；网页可从 `letter-spacing: normal` 起步，但不宣称原图实测为 0px。不通过压扁字体、单行无限缩小来塞满卡片。

## 语义断行

先写具体结论，再找自然停顿，设置一至两行，检查长度与重心，最后决定字号。左右齐、居中都可以成立，同一文字组须有稳定对齐。

```text
把重点，
放在眼前。
```

不要为复制这种节奏，强迫所有内容使用同一个句式。项目名、数字或产品也可承担主角。

## 空间比例

设 H 为当前展示标题字号：

- 引子到标题：约 0.5H 的可见空隙。
- 标题到说明：约 0.7–0.8H 的可见空隙。
- 中文标题行高：约 1.08–1.20 起步。
- 中文说明行高：约 1.45–1.65 起步。

前两个比例来自原图的近似标注；本页中文行高范围是实施建议。原图另有英文 1.2 倍行距、中文 6pt 标题段距以及三组中文实例，不能混成一个行高参数。可见空隙指字形边界的距离。字体升降部、CSS 行框、段前/段后设置会改变实际观感，`margin: .75H` 不保证视觉上也空出 .75H。

普通网页正文可从 16–20 CSS px 起步；远距海报需另算最小字，不把信息墙小标签当成所有正文的字号标准。英文短说明可以更紧凑，不直接套用于长中文。

## 颜色服务内容

中性底负责秩序，局部强色负责聚焦。四类起步方向：

| 视觉性格 | 处理方法 | 注意 |
|---|---|---|
| 性能、力量 | 深底、实白字、少量冷暖对比 | 颜色不能替代性能证据 |
| 轻薄、空气感 | 灰蓝、浅底、较轻字重、颜色渐浅 | 渐变浅端仍须可读 |
| 灵动、柔和 | 相邻紫蓝绿的平滑过渡 | 用于完整短语，避免逐字换色 |
| 清晰、冷静 | 同色系深浅变化 | 适合一个关键词或核心数字 |

可选起步色板：浅底文字用原图深蓝 `#024F97 → #1D6EB6`；深底可适配为 `#7BAED1 → #2997FF`，后者是实施组合。柔和标题的原图四节点为 `#A07AC7 → #8580C7 → #7189BC → #659955`；如简化为三个节点，注明为调整。暖冷双色、灰蓝轻薄等完整色板及箭头方向见台账第 5 节。先检查实际背景，不将整套调色同时应用到每张卡。

明确渐变范围、方向与节点：横向通常适合一条短语，纵向可突出同一字形的明暗重量。方向要响应具体构图，不是固定的语义编码。

整页通常使用一套主渐变加必要的功能实色。正文、单位、来源保持实色。无法保证渐变可读性或工具支持时，使用色板中的一个实色即可。

## 对比与检查

普通文字可用 4.5:1、大字可用 3:1 作为检查目标；测试实际背景与渐变中间色，不能只看两端。深浅主题需要分别调整。

遮住图片看文字是否仍有主次；遮住文字看图片是否只围绕一个明确特征。若所有卡都靠彩色粗字、胶囊和立体小物件区分，就需要改变角色与布局。
