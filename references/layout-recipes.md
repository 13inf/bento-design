# 布局与实现配方

配方帮助选择，不是每次都要使用的固定模板。具体文字、事实和载体优先。原图卡缝 16/24pt、短边 18% 圆角近似与各组文字参数见 [参考图参数台账](reference-measurements.md)；下方网页示例使用的是适配值。

## 四种主导方式

| 任务 | 布局 | 字图关系 |
|---|---|---|
| 说清一句主张 | 文字主卡，少量辅助卡 | 大字主导，解释退后，产品可小 |
| 展示一个特征 | 产品特写＋短句 | 侧面、材质、轮廓与空白一起表达 |
| 扫描一组规格与功能 | 信息 Bento | 大主卡与不同角色小卡建立秩序 |
| 展示多件作品 | 图像画廊 | 图像姿态带来张力，阅读区保持安静 |

## 信息墙

```text
┌──────┬───────────────┬──────┐
│ 功能 │   横向细节图  │ 数据 │
├──────┼───────────────┼──────┤
│ 数据 │               │ 功能 │
├──────┤   核心主卡    ├──────┤
│ 功能 │               │ 数据 │
├──────┼───────────────┼──────┤
│ 辅助 │   横向要点    │ 辅助 │
└──────┴───────────────┴──────┘
```

主卡可跨列跨行，允许偏置，不为对称添加无用内容。外围可以是小文字、数字、图像局部，不把每格都做成一篇缩小文章。

## 文字主卡

```text
┌──────────────────┬──────────┐
│ 小引子           │ 深色卡   │
│ 两行大主张       │ 短句主导 │
│                  │ 少量说明 │
│ 短解释           ├──────────┤
│ 可选产品局部     │ 产品细节 │
├──────────────────┴──────────┤
│ 次级信息 / 简短流程 / 署名   │
└─────────────────────────────┘
```

文字主卡可无图，也可没有外框。黑卡只承担局部视觉重量，不能把每卡都加一根深色标题条。

## 产品特写

先选择特征，再选择尺度和裁切：侧面描述薄度，微距描述材质，屏幕内容描述功能。不要用一张环境全景覆盖所有主题。

文字可在图的上方、下方或自然空白中。少量手部可表达尺度与操作，非必要不引入人物。概念产品图明确标注，不冒充真实型号。

## 多图画廊

先搭可以对齐的网格，再让少数图片倾斜或出画，保留正向文字区。窄屏先取消旋转并重排，不用缩小整张桌面海报替代适配。

## 逐卡分工

为每卡选一个主导方式：大字、数字、图像、关系或次要文字。一页不必凑齐全部类型；等大卡也要有轻重、明暗、位置和姿态变化。

## 网页起步

[tokens.css](../assets/tokens.css) 使用 `bd-` 局部类名与变量，不引入全局 reset、远程字体或框架。复制到目标项目后只用需要的部分。

```html
<section class="bd-surface" aria-labelledby="feature-title">
  <div class="bd-container">
    <header class="bd-section-heading">
      <p class="bd-eyebrow">产品体验</p>
      <h2 id="feature-title">让信息，自有主次。</h2>
    </header>
    <div class="bd-grid">
      <article class="bd-card bd-hero bd-statement">
        <p class="bd-kicker">一条清晰主张</p>
        <h3 class="bd-headline">
          <span class="bd-line">把重点，</span>
          <span class="bd-line bd-gradient bd-gradient-cool">放在眼前。</span>
        </h3>
        <p class="bd-deck">提供与当前主张直接相关的真实说明。</p>
      </article>
      <article class="bd-card" data-bd-tone="dark">
        <h3>一项具体能力</h3>
        <p>说明它给使用者带来的意义。</p>
      </article>
      <article class="bd-card">
        <h3>必要的辅助信息</h3>
        <p>没有数据就保留准确文字，不补造参数。</p>
      </article>
    </div>
  </div>
</section>
```

此 HTML 仅演示结构，不是视觉验收通过的成品。

默认四列，窄屏两列，小屏一列。`bd-hero` 跨两列；足够侧卡与合适内容支持跨行时，再加 `bd-hero-tall`。窄屏取消跨行，小屏取消跨列。不要使用自动密集填充改变语义阅读顺序。

整区可用 `data-bd-theme="white"`、`"dark"` 或 `"black"`；局部深卡用 `data-bd-tone="dark"`。正文和渐变要分别验证对比度。

`bd-statement` 提供约 3:1 字级差与相对间距起点；显式 `bd-line` 仅用于语义换行，窄屏仍需检查孤字和溢出。字号与文字组关系见 [字重与色彩](typography-color.md)。

## 实现细节

- 用 Grid/Flex 分配图像空间，避免靠绝对定位制造文字冲突。
- 标准圆角用长度值保持弧度一致；百分比在宽高不同的卡里会产生不同曲线，不冒充连续曲率。
- 关键文本不能被 `overflow: hidden` 截断；变长中文、单位和换行需要实际检查。
- 信息卡没有操作就不添加手型、空链接或抬升动画。真实控件保留清晰焦点。
- 默认无需动效；需要时支持减少动态效果，不能借动画隐藏正文或造成阅读次序改变。
